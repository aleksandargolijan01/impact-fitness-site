# Impact Fitness Site

One-page Angular landing page for the Impact Fitness gym in Belgrade.

## Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm start
```

Open `http://localhost:4200/`.

## Build

Create a production build:

```bash
npm run build
```

## Tests

Run unit tests:

```bash
npm test -- --watch=false
```
